## 二、四处必须纠正

### ① 401 vs 403

```
401 Unauthorized  = 没登录 / 凭证无效      → 去登录
403 Forbidden     = 登录了，但没这个权限    → 换账号也没用
```

类比：401 是"没带门禁卡"，403 是"有卡，但这是机房，你进不去"。

### ② `self` 是什么

**不是"函数本身"，是"正在创建/使用的那个对象自己"。**

```python
class Dog:
    def __init__(self, name):
        self.name = name      # self = 这只狗

d = Dog("旺财")
print(d.name)                 # 旺财 —— 这里的 d 就是 self
```

`__init__` 被调用时，`self` 指向的正是 `d`。

### ③ `__name__` 的值

| 使用方式 | `__name__` |
|---|---|
| `python a.py`（直接运行） | `"__main__"` |
| `import a`（被别人导入） | `"a"` |

记法：**直接跑 = 主角（`__main__`）；被导入 = 配角（模块名），别自己开演。**

### ④ `ss -tlnp`

| 参数 | 含义 |
|---|---|
| `-t` | TCP |
| `-l` | listening（监听中） |
| `-n` | 用数字显示端口 |
| `-p` | 显示对应进程 |

一句话：**谁在监听哪些 TCP 端口、是哪个进程。** 输出先看 `Local Address:Port` 列。
