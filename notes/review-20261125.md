## 二、两处必须纠正

### ① 不写 `raise` 会发生什么（第 2 题）

```python
except requests.exceptions.Timeout as exc:
    last_error = exc
    logger.warning("第 %d 次超时", attempt)
    raise       # ← 立刻抛出，重试失效（只跑 1 次）
```

**正确理解**：
- 写 `raise` = 放弃，函数立刻结束 → 重试逻辑完全失效
- 不写 = 异常被咽下，循环继续下一轮 → 3 次都失败后在**循环外**统一 `raise last_error`

不是"等到 timeout 再报错"，异常已经被 catch 住了，不会自己冒出来。

### ② 为什么二分是 `while left <= right`（第 9 题）

闭区间写法下（`right = len(nums) - 1`），**`left == right` 时还有一个元素没检查**：

```
nums = [5], target = 5
若写 while left < right: 一次都不进 → 返回 -1  ❌
写 while left <= right:  会检查 nums[0] → 命中 ✅
```

与"空值"无关：空数组时 `left=0, right=-1`，`0 <= -1` 为假，天然安全。

### 缺口 1：git 颜色与分开提交（0 分，天天用）

```powershell
git status          # 红色 = 改了没 add

git status          # 绿色 = 已 add 待 commit

```

**验收**：能不看资料说出"红→绿→提交→推送"，以及"分开提交 = 一次 add 一个文件后立刻 commit，最后统一 push"。

### 缺口 2：ETag 与协商缓存（40%）

> `ETag` 是内容**指纹**。第二次请求浏览器带 `If-None-Match: "指纹"`，服务器比对：
> 没变 → **304**（不带响应体，省流量）；变了 → **200 + 新内容**。
>
> 分工：`max-age` 管"多久不用问"（强缓存）；`ETag` 管"问的时候怎么判断变没变"（协商缓存）。
